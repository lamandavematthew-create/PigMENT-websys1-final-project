# PigMENT — Registered Pigs icons

Matching recreations of the icons visible in the supplied Registered Pigs screenshot. They are **not extracted original vector files**.

13 icons, each provided in transparent PNG (256 × 256) and scalable SVG formats:
- pig-outline (white on green header)
- search, chevron-down
- breed-layers, male, calendar, age-sprout, weight-scale, pen-house
- view-eye (white on green button), edit-pencil, delete-trash
- active-dot (green active-status bullet)

For icons used on colored backgrounds, use the exact file and keep the background in CSS. Example:

```html
<img src="/public/assets/icons/calendar.svg" alt="" aria-hidden="true" width="24" height="24">
```

Use the image versions if needed, but SVG scales better for the website.
